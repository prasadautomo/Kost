Aktivasi Google Login di Supabase

Hubungkan Google Cloud Console ke Supabase Cloud

Agar login dengan Google asli (Live OAuth) dapat berfungsi, Anda perlu mengaktifkan provider Google di dashboard Supabase Anda:

1. Redirect URL (Callback Supabase):
  1. Buka Google Cloud Console > Credentials > Buat OAuth Client ID (Web Application).
  2. Tambahkan URL di atas ke kolom Authorized redirect URIs.
  3. Buka Supabase Auth Providers ↗, aktifkan Google, dan tempel Client ID serta Client Secret.
🚀 Buka Supabase Providers ↗

Buka via Server Web (Localhost / Vercel)

Google OAuth melarang pengalihan ke URL file://

Anda sedang membuka aplikasi langsung melalui berkas lokal (file:///). Google OAuth resmi mewajibkan aplikasi dijalankan melalui web server lokal (http://localhost) atau hosting HTTPS (seperti Vercel).

Cara Cepat Menjalankan Server Lokal:
powershell -File serve.ps1
Otomatis membuka http://localhost:3000 di browser Anda.

🌐 Aktifkan Penyimpanan Web Supabase (Cloud Storage)

💡 Mengapa data belum tersimpan langsung ke web?
Supabase secara default mengaktifkan Row Level Security (RLS) yang menolak penyimpanan data dari web browser. Jalankan skrip di bawah ini sekali saja di SQL Editor Supabase Anda agar semua data penghuni, kamar, pembayaran & pengeluaran otomatis tersimpan langsung ke web! 


      

        
Langkah Cepat (1 Menit):

        
    
          
  1. Klik tombol "📋 Salin Skrip SQL" di atas.
    2. 
          
  2. Buka Supabase SQL Editor di tab baru dengan tombol di bawah.
    3. 
          
  3. Tempelkan skrip (Ctrl+V) dan klik tombol hijau "RUN" (Ctrl+Enter).
    4. 
          
  4. Kembali ke sini dan klik "🧪 Uji Izin Simpan Web". Selesai!
